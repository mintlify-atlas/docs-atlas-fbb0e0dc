Earshot turns audio files into evidence that a coding agent can reason about. It answers questions like "what does this sound like?", "does this match the brief?", "where in this recording does a key press happen?", and "is this a real recording or code-generated?" — all running locally on CPU, with no cloud services after an initial model download.

## What Earshot does

Earshot exposes every capability both as a CLI command and as a Python function. Models load once and stay warm inside a Python process or the MCP server; each CLI call loads them fresh (~20-40 s) unless you use `earshot sfx` or `earshot kit`, which use no models at all.

| Command | What an agent gets |
|---|---|
| `describe FILE` | Calibrated natural-language tags (z-score), AudioSet labels, and measurements |
| `match FILE QUERY` | How well a description fits: cosine, z-score verdict (strong / plausible / weak / no match) |
| `rank QUERY PATHS...` | Many files sorted by a description — pick the best candidate |
| `find FILE QUERY` | Best moments inside a long recording, returned as sample trims |
| `compare FILE --refs DIR` | Nearest reference recordings; `ab A B` differences in words |
| `realness FILE...` | Real recording vs code-synthesized, per-window scores |
| `timeline FILE` | Listening transcript: events, sections, loudness, beat grid, sync to picture |
| `sheet FILE -o out.png` | Annotated PNG (waveform, spectrogram, events, frames) for visual agents |
| `critique FILE` | Scorecard against a profile of professional launch films |
| `measure FILE` | Objective measurements only — no models: LUFS, LRA, spectrum, tempo |
| `forge RECIPE` | Make sounds in code and improve them by listening |
| `fit FILE` | Translate a recording into a forge recipe module |
| `sfx render ID` | Render one of 201 built-in sounds by id, aimed at the picture |
| `kit init / render` | Render a whole film's sound effects kit with measured sync points |

## Key properties

<CardGroup cols={3}>
  <Card title="CPU-only" icon="microchip">
    No GPU needed. Runs on any laptop. Two open models (~1.1 GB total) download once, then work offline.
  </Card>
  <Card title="Agent-native" icon="robot">
    Every command prints a plain-language summary first. `--json` gives structured output. Errors are one line on stderr.
  </Card>
